### 🚀 Selected Projects

- **[blockchain-indexer](https://github.com/sanketlakhera/blockchain-indexer)**  
  High-throughput Ethereum blockchain indexer in Rust using Tokio, Alloy, and transactional PostgreSQL persistence. Features compile-time ABI decoding (`alloy::sol!`), relational schema indexing, and strict ACID persistence boundaries.

- **[trade-engine-in-rust](https://github.com/sanketlakhera/trade-engine-in-rust)**  
  In-memory limit orderbook matching engine in Rust with multi-market support, BTreeMap price levels, and price-time priority execution.

- **[http_server](https://github.com/sanketlakhera/http_server)**  
  A zero-dependency HTTP/1.1 server written from scratch in Rust using `std::net::TcpListener`. Features zero-copy byte parsing leveraging Rust lifetimes (`Request<'buf>`), custom handler traits, and raw TCP stream I/O.

- **[port-watcher](https://github.com/sanketlakhera/port-watcher)**  
  Cross-platform command-line utility in Rust for monitoring and managing active TCP ports and processes.

- **[file-scanner](https://github.com/sanketlakhera/file-scanner)**  
  Concurrent directory and disk usage analyzer written in Go with table-driven unit tests.
